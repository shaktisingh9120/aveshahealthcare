# Medora RCM – multi-page website template

Pages: index.html (Home), about.html, specialties.html, platforms.html (Platforms & AI), resources.html, careers.html.
Shared styles and scripts: assets/style.css, assets/script.js.

## Run
Open index.html in a browser, or upload the whole folder to any static host (Netlify, Vercel, cPanel, GitHub Pages).

## Customise
- **Brand name, phone, email:** "Medora" is a placeholder brand. Edit `BRAND` and the contact lines in build.py and run `python3 build.py`, or search-and-replace in the HTML files.
- **Background photos:** set at the top of assets/style.css (`--img-home`, `--img-about`, …). They are dummy Unsplash photos; replace the URLs with your own images (for example `url("assets/hero.jpg")`).
- **Colours and fonts:** `--navy`, `--teal`, `--f-head`, `--f-body` at the top of assets/style.css.
- **Forms:** contact, newsletter and job-application forms show a confirmation only. Connect them to your backend or a form service (Formspree, HubSpot, etc.).
- Numbers, case studies, testimonials, awards, leadership and job listings are sample content. Replace them before going live.
